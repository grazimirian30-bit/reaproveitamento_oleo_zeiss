# Óleo Consciente — PFE
Site educativo sobre aproveitamento e reciclagem de óleos e gorduras residenciais, para a Carl Zeiss.

## Estrutura
- Sete páginas HTML: Início, Impactos, Armazenamento, Coleta, Educação, Dicas e Projeto.
- `css/style.css`: **Tarefa 8 (Design)** — cores, aparência, responsividade.
- `js/script.js`: **Tarefa 9 (Programação)** — menu, navegação e quiz.
- `imagens/`: arquivos `inicio.webp`, `impactos.webp`, `armazenamento.webp`, `coleta.webp`, `educacao.webp`, `dicas.webp` e `projeto.webp`.

**Importante:** as sete imagens estão no pacote ZIP entregue no ChatGPT. É necessário carregar esses sete arquivos na pasta `imagens/` deste repositório para que apareçam nas páginas.

## Como executar
Abra `index.html` em um navegador, ou publique usando GitHub Pages nas configurações do repositório (branch `main`, pasta raiz).

## Divisão
- Tarefa 7: revisar requisitos e navegação.
- Tarefa 8: revisar o layout, cores e ilustrações.
- Tarefa 9: implementar funcionalidades e integrar o site.
- Testes e conteúdo: revisão posterior com a equipe.

Protótipo inicial: validar conteúdo, pontos de coleta e autorização escolar antes de divulgação institucional. Não coletar dados pessoais dos estudantes.
